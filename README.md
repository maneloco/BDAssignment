## 1. Description
This repository contains the code, validation data, raw measurements, and plots for **Assignment 1**. The goal is to compare the basic $O(n^3)$ triple-loop matrix multiplication algorithm (`i-j-k` order) in **C**, **Java**, and **Python**, analyzing how the matrix size $n$ affects execution time and memory usage under controlled conditions.

To make sure the comparison is fair and all three languages compute the exact same operation:
1. A C program (`src/c/generate_and_validate.c`) creates a shared file (`data/validation_suite.txt`) with 4 small test cases (Identity $4\times 4$, Zero $4\times 4$, a known $3\times 3$ matrix, and a random $32\times 32$ matrix) and their solutions.
2. Before running the benchmarks, C, Java, and Python read this file and verify that they produce the same solution (within `1e-9` tolerance) and that their custom 64-bit Linear Congruential Generator (`seed = 42`) produces the exact same numbers in all three languages.
3. Every benchmark run computes and logs a `checksum` (the sum of all elements in matrix $C$) outside the timer to verify that the results match for every size $n$.

## 4. How to Run and Reproduce

### Step 1: Install Python dependencies for plotting
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Step 2: Run the complete benchmark suite
This script records the system info, generates the validation file, compiles C and Java, runs all benchmarks, and generates the CSV tables and plots:
```bash
chmod +x run_all.sh
./run_all.sh
```

### Step 3: Run only the analysis and plots (if `raw_measurements.csv` is already generated)
```bash
source .venv/bin/activate
python3 scripts/analyze_results.py
```
